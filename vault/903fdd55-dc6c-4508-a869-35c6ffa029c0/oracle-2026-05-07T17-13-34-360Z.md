# 策略分析文档 — 橘猫图片生成与部署

## 1. 需求概述

通过 AI 绘图 API 生成一张指定风格的橘猫图片，下载后放置到 Windows 桌面。

---

## 2. 任务拆解

| 序号 | 任务 | 描述 | 类型 | 优先级 |
|------|------|------|------|--------|
| 1 | 风格与参数选型 | 确定图片风格（写实/插画/像素）、尺寸（1920×1080）、猫咪姿态等 Prompt 参数 | **forge** | 🔴 高 |
| 2 | API 选型与接入 | 对比 Stable Diffusion / DALL·E / Midjourney 等方案，选定 API 并完成调用封装 | **forge** | 🔴 高 |
| 3 | 图片生成 | 调用选定 API，传入 Prompt 生成橘猫图片，返回图片 URL 或 Base64 | **hermes** | 🟡 中 |
| 4 | 图片下载与桌面部署 | 将生成结果下载到本地，写入 `%USERPROFILE%\Desktop\` | **forge** | 🟡 中 |
| 5 | 结果验证 | 检查图片文件完整性（非空、可打开），记录生成日志 | **forge** | 🟢 低 |

---

## 3. 技术方案推荐

### 3.1 AI 绘图 API 对比

| API | 优点 | 缺点 | 推荐度 |
|-----|------|------|--------|
| **Stable Diffusion (本地/云端)** | 开源、免费、可控性强、支持 LoRA 微调 | 需 GPU、部署复杂 | ⭐⭐⭐⭐ |
| **DALL·E 3 (OpenAI)** | 质量极高、Prompt 理解强、使用简单 | 需付费 API Key、国内访问受限 | ⭐⭐⭐ |
| **Midjourney** | 艺术质量最佳 | 无公开 API，仅 Discord 交互 | ⭐⭐ |
| **字节 Seedance** | 国内直连、已配置 SDK (`volcengine-ark`) | 偏视频生成，图片能力需验证 | ⭐⭐⭐ |

### 3.2 推荐实现路径

```
用户需求 → forge(选型+封装) → hermes(调用API生成) → forge(下载到桌面) → forge(验证)
```

**建议选 Stable Diffusion WebUI API** 或 **字节 Seedance（已有 SDK）**，前者免费可控，后者免翻墙。

---

## 4. 关键风险提示

| 风险 | 影响 | 应对 |
|------|------|------|
| **GFW 网络阻断** | DALL·E / Hugging Face 等 API 不可达 | 优先选国内方案（Seedance）或本地 SD |
| **API 费用** | 生成多张图时产生不可控成本 | 先用免费额度/本地模型跑通再切换 |
| **Prompt 不可控** | AI 出图可能偏离预期 | 预设 3 套 Prompt 模板，批量生成后人工挑选 |
| **WSL 与 Windows 文件交互** | Hermes 在 WSL 中，写 Windows 桌面需跨文件系统 | 使用 `/mnt/c/Users/...` 路径或走 HTTP 中转 |
